# Shop example

The shop is AAT's offline quick start. `aat-sandbox` serves its API on your machine, `aat-sandbox init shop`
extracts the project, and the repository keeps it at
[`examples/shop`](https://github.com/gburgyan/aat/tree/main/examples/shop). The rest of this page is that
project's README.
